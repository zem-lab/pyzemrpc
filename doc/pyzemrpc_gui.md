# pyzemrpc

ZEPTOOLS扫描电子显微镜(SEM)远程控制图形界面应用。

## 功能描述

`pyzemrpc`是pyzemrpc包的主图形用户界面(GUI)应用程序，提供了交互式的扫描电子显微镜控制界面。

## 使用方法

```bash
pyzemrpc
```

启动后设备下拉框默认是 **本机**（`127.0.0.1:61557`），对应本机虚拟 ZEM 或本机电镜代理。

1. 本机已监听 `61557`：直接点「同步状态」。
2. 局域网设备：点「扫描在线设备」，再从下拉框选择 `ip:port`。
3. 本机服务未开时同步会超时，弹窗：`命令超时，可能电镜服务未开启`。

扫描只追加发现结果，「本机」项保留在第一项，且不会再出现一条重复的 `127.0.0.1:61557`。

## 主要特性

- 图形化控制界面
- 默认本机设备，可直接同步，无需先扫描
- 实时图像显示
- SEM参数控制
- 工作台位置管理
- 扫描参数配置
- 图像保存和元信息管理

## 鱼眼未标定时的图像显示

鱼眼直接 DAC 尚无有效场宽标定时，Shell 返回 `ScanWidth=ScanHeight=0`，表示物理场宽未知。图像仍可正常采集，显示端使用实际像素尺寸，保持像素比例，并在工具栏标明像素坐标。此时不提供图像右键「移动至此」，避免将像素值误当作台位。场宽和台位有效时继续使用原来的样品台坐标显示。

JSON-RPC 拍图的倍率、电压、台位、场宽和焦点元数据取自本次响应，不沿用连接时缓存；完整响应元数据保存在 `rpc_meta`。无场宽时 `FieldSize`/`PixelSize` 为 0、`bounds` 为 None。已保存的零面积 bounds 图像也按像素显示。

2026-09-28 排查确认：512×512 原图数据完整，但旧显示器把零面积 bounds 传给 matplotlib，坐标轴自动扩展后呈长方形，图像本身没有可绘制面积。修复见 [拍图坐标说明](20260928_snapshot_geometry.md)。

## 系统要求

- Python 3.11+
- PySide6 (Qt绑定)
- pyqtgraph (数据可视化)
- opencv-python (图像处理)

## 配置文件

应用程序使用配置文件 `conf/config.yml`，安装时位于:
- Windows: `%APPDATA%/zemrpc/conf/`
- Linux/macOS: `~/.local/share/zemrpc/conf/`
