# PerlinZem 虚拟电镜开发工作汇报

## 一、项目背景

为了支持电镜软件的开发测试和演示需求，需要开发一个基于柏林噪声（Perlin Noise）算法的虚拟电镜 `PerlinZem`，替代原有的 Mandelbrot 分形电镜，生成更接近真实电镜图像纹理的模拟图片。

## 二、核心需求

1. **生成导航图**：能够生成类似真实电镜的导航图像
2. **区域拍照**：对指定的台架位置和放大倍率生成对应的拍照图片
3. **无限放大**：支持任意放大倍率，高倍率下仍有丰富细节
4. **可重复性**：同一区域多次生成的图案完全一致，保证测试结果可复现

## 三、技术实现

### 3.1 柏林噪声算法

- 实现了向量化的 2D 柏林噪声计算 `_perlin_2d_vectorized()`
- 使用确定性随机种子初始化排列表，保证噪声场可重复
- 采用平滑插值函数 `6t^5 - 15t^4 + 10t^3` 减少视觉伪影

### 3.2 分形布朗运动（FBM）

- 实现 `_fbm()` 方法叠加多层不同频率和振幅的噪声
- 支持动态调整 octaves（层数）、lacunarity（频率增长因子）、persistence（振幅衰减因子）
- 高倍率时自动增加细节层数，实现"无限放大"效果

### 3.3 图像生成

- `_generate_perlin_image()`: 根据物理坐标范围生成指定尺寸的噪声图像
- 添加多层纹理叠加：基础噪声 + 细节噪声 + 颗粒效果
- 支持 uint8 和 uint16 两种图像深度输出

### 3.4 接口实现

| 方法             | 功能                                                |
| ---------------- | --------------------------------------------------- |
| `get_nav_img()`  | 返回 640x480 导航图（使用 `@cached_property` 缓存） |
| `snap(req)`      | 响应 UDP 协议拍照请求                               |
| `snap_jsonrpc()` | 响应 JSON-RPC 拍照请求                              |

## 四、关键参数

| 参数             | 值     | 说明                         |
| ---------------- | ------ | ---------------------------- |
| `seed`           | 42     | 随机种子，保证可重复性       |
| `nav_scale`      | 500 um | 导航图覆盖的物理范围         |
| `base_frequency` | 0.05   | 柏林噪声基础频率             |
| `octaves`        | 6~12   | FBM 层数（根据倍率动态调整） |

## 五、配置使用

在 `config.yml` 中设置虚拟电镜类型：

```yaml
virtual_zem:
  type: perlin  # mandelbrot, perlin, replay
```

## 六、技术特点

1. **确定性**：使用固定种子初始化，同一坐标始终生成相同噪声值
2. **高性能**：采用 NumPy 向量化计算，避免逐像素循环
3. **无限细节**：FBM 算法叠加多层噪声，放大不失真
4. **兼容性**：完全兼容现有 `VirtualZem` 接口，可无缝切换

## 八、后续优化方向

1. 图像边缘锐利度优化，改善高倍率（几万倍）下的模糊问题
2. 添加更多电镜特征纹理（如晶格、颗粒边界等）
